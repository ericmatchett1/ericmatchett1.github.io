Inner Monologue: Closed-Loop Reasoning with Language Models

Closing the loop between a language-model planner and the world by feeding perception, success detection, and human feedback back to the model as language — so it can re-plan as conditions change.

Everyday Robots · Google Research  ·  2022  ·  My role: contributor (closed-loop planning)

LLM PlanningClosed-LoopFeedbackRobotics

My contribution

I contributed to Inner Monologue, focusing on closed-loop planning — using language as the medium for feedback so a language-model planner could observe outcomes, recover from failures, and adapt its plan during execution.

Closed-loop planning

Re-planned each step based on what actually happened.

Feedback grounding

Turned perception, success checks, and human input into language the model could use.

Robust recovery

Detected failures and adjusted, improving long-horizon reliability.

Evaluation

Studied how feedback types affected task success.

Technical overview

  • An LLM planner proposes the next step toward a natural-language goal.
  • Outcomes — scene descriptions, success detection, human hints — are returned as text.
  • The planner incorporates that feedback and revises its plan on the fly.
  • This loop makes execution more robust in changing, unstructured environments.

Results & impact

Adaptive plans

The robot recovered from errors instead of blindly following a fixed plan.

Language as the interface

Diverse feedback unified into one textual channel the LLM understood.

More reliable tasks

Closing the loop improved success on longer instructions.
