Overview

SayCan is a system for telling a robot what to do in plain language and having it carry out long, multi-step tasks in the real world. The core idea is to pair the broad knowledge of a large language model with what a specific robot is physically able to do in its current situation — so the plan it produces is both relevant to the request and achievable with the robot's learned skills.

The name captures the two halves of the method: "Say" — the language model proposes useful next steps for the goal — and "Can" — learned value functions estimate how likely each skill is to succeed from the robot's current state. Combining the two lets the robot choose actions that are simultaneously sensible and feasible, then execute them step by step.

How it works

Say — language model

A large language model scores a library of low-level skills (e.g. "pick up the sponge", "go to the table") by how useful each one is for completing the natural-language instruction.

Can — affordance values

Learned value functions estimate the probability that each skill can be executed successfully from the robot's current observation, grounding language in the physical world.

At every step, the two signals are multiplied: the robot picks the skill that maximizes usefulness × feasibility, runs it, observes the result, and repeats — composing simple skills into long-horizon behavior without a hand-written plan.

Highlights

  • Executes long-horizon, natural-language instructions on real mobile manipulators in everyday environments.
  • No task-specific planner — behavior emerges from grounding an LLM in learned robot affordances.
  • Foundational to later work combining language, perception, and action (RT-2, PaLM-E, Inner Monologue).
  • Widely covered: reported by 260+ media outlets including TechCrunch, WIRED, Reuters, and The Washington Post.

My contribution

As a Staff Research Scientist at Everyday Robots, I co-led the SayCan effort — working on using large language models for robot planning and reasoning, and on connecting language-level intent to the robot's learned, low-level skills so that instructions could be carried out reliably in unstructured settings.
