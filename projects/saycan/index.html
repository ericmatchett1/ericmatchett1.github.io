SayCan: Grounding Language Models in Robotic Affordances

Connecting large language models with robotic affordance and value functions so a robot can choose actions that are both useful for the instruction and physically feasible in its environment.

My contribution

I contributed to the SayCan project, focusing on the intersection of language reasoning, robotic action planning, and evaluation workflows — connecting high-level semantic understanding with the robot's low-level, learned skills so that natural-language instructions could be carried out reliably in real environments.

Technical overview

SayCan lets a robot follow plain-language instructions by combining two complementary signals at every step of a task:

  • What is useful — a language model proposes the actions that make sense for the instruction.
  • What is possible — an affordance model estimates which actions can actually be executed in the current environment.
  • SayCan score — the system combines usefulness with feasibility, so the chosen action is relevant and achievable.
  • Step by step — the robot performs the best action, observes the new state, and re-plans the next one until the task is complete.

How a decision is made

  1. User instruction

    A natural-language goal, e.g. "Bring me a snack and a drink."

  2. LLM candidate actions

    The language model proposes skills that are useful for the goal — "what makes sense."

  3. Affordance scoring

    Value functions score how feasible each skill is right now — "what's possible."

  4. Combined SayCan score

    Usefulness × feasibility selects the next best action to execute.

  5. Robot action execution

    The robot performs the highest-scoring skill in the real world.

  6. Observe & repeat

    It senses the new state and plans the next step — until the task is done.

Results & impact

Interpretable decisions

Separating "useful" from "possible" makes each robot choice easier to understand and debug.

Reliable long-horizon tasks

Composing simple skills enabled more dependable execution of multi-step instructions.

Reasoning meets feasibility

Connected semantic intent with real-world robotic capability, not just plausible text.

Grounded language models

Demonstrated how LLMs can be grounded in physical environments through learned affordances.
