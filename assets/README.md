# Media assets

Drop your real files here to populate the **"See my work in action"** thumbnails.
`index.html` references these filenames:

| File | Used for |
|------|----------|
| `saycan.jpg`       | SayCan thumbnail (image) |
| `rt2-demo.mp4`     | RT-2 thumbnail (video) |
| `video-poster.jpg` | Poster shown before the RT-2 video plays |
| `palm-e.jpg`       | PaLM-E thumbnail (image) |
| `portrait.jpg`     | Optional sidebar photo (commented out in `index.html`) |

Tips:
- Thumbnails are cropped to a 4:3 ratio automatically.
- Keep videos small (a few MB) — GitHub Pages does no transcoding.
- To add the sidebar photo, drop `portrait.jpg` here and uncomment the
  `<img class="portrait" ...>` line in `index.html`.
