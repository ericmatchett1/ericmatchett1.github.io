## Videos
The Videos page and home page stream demo clips directly from official
first-party sources (Google Research project pages, Waymo's CDN, X's CDN) —
no files needed here for those. They are all self-hosted mp4/gif, never YouTube.
To make a clip permanent, download it into this folder and update the
`<source src="...">` in the relevant HTML page.
